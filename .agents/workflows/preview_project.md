# Preview Project Workflow

This workflow will start the local development server to test the application.

1. Ensure dependencies are installed first (`npm install`).

2. Run the Next.js development server:
// turbo
```bash
npm run dev
```

3. Open a browser and navigate to the provided localhost URL (usually `http://localhost:3000`).
